# Qui suis-je ?

Un petit jeu de cinq questions pour faire connaissance avant une formation : mes goûts, mon métier, mes passions. Trois bonnes réponses dévoilent ma photo.

Le jeu s'ouvre dans un navigateur et ne collecte aucune donnée : rien n'est envoyé ni enregistré.
